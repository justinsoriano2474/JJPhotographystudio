JJ PHOTOGRAPHY STUDIO - MULTI-PAGE WEBSITE

1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser (or use the Live Server extension).
4. Keep all six HTML files and style.css together in the same folder.
5. For gallery photos, create a folder named images and add:
   sunset.jpg
   nature.jpg
   portrait.jpg
   Or change the image paths in gallery.html to match your photo filenames.

The booking form uses FormSubmit and sends requests to jjphotographystudio1@gmail.com.
The first submission may require email confirmation from FormSubmit before it works.
The package prices are examples; update them if needed.
